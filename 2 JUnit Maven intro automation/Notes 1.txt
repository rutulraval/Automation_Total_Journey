Selenium Disadvantages
❌ Supports only web applications
❌ No dedicated support community
❌ No built-in reporting (needs third-party plugins)
❌ Limited support for image-based testing (Use Sikuli)

Selenium Advantages
✔ Open-source
✔ Supports multiple OS & programming languages
✔ Supports multiple browsers, including headless browsers (cross-browser testing)
✔ Parallel execution support
✔ Supports frameworks like TestNG, JUnit, NUnit

Client-Server Architecture
------------------------------
✔ When a browser opens a website → The page is fetched from a server
✔ The server is a program written in Java
✔ Containers create objects of the server → Access its methods & services

This is called multi-tier architecture 🔄

✔ Example:
1️⃣ Front-end sends authentication request to server
2️⃣ Server checks the database
3️⃣ Server sends the appropriate page back to front-end

✅ This represents MVC architecture (Model-View-Controller)
