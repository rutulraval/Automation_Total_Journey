JUnit Annotations & WebDriver Setup
Importing @Test Annotation (59:00)
✔ Required Import:
import org.junit.Test;

Optimizing WebDriver Setup (01:27:00)
❌ Wrong Practice:

Using WebDriverManager.chromedriver().setup(); and new ChromeDriver(); inside every test

✅ Best Practice:

Create a global WebDriver object

Use @Before annotation to initialize WebDriver only once

Use @After annotation to quit WebDriver after tests

Optimized Code Using JUnit Annotations

import org.junit.Before;
import org.junit.After;
import org.junit.Test;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;
import io.github.bonigarcia.wdm.WebDriverManager;

public class MyTest {

    private WebDriver d = null; // Global WebDriver object

    @Before
    public void setup() {
        WebDriverManager.chromedriver().setup();
        d = new ChromeDriver();
    }

    @Test
    public void testSomething() {
        d.get("https://www.google.com");
        // Your test steps here...
    }

    @After
    public void cleanUp() {
        d.quit(); // Close the browser after every test case
    }
}
Explanation of JUnit Annotations
✔ @Before → Runs before every test case (sets up WebDriver)
✔ @After → Runs after every test case (closes browser)
✔ @Test → Marks a method as a test case

This reduces redundant code, making test execution faster & efficient!
