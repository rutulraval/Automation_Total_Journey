Why do we use iFrame (Inline Frame)?
- same reason as shadowDom
- To separate components from interfering with each other.
- It embeds different kinds of media, images, videos and advertisements on the main web-page.
- Risk of cross-site scripting. Because it is hosted at external site.
- Trusting procedure should be completed.

Syntax
<iFrame src="url"></iFrame>


These iFrame elements can't be located using usual selenium techniques.

Frames are the HTML tags that divide the browser window into multiple parts(vertical/horizontal)
<frameset> is usually parent tag containing multiple <frame> tags


<iFrame> can be placed inside <body> tag.

iFrame and Selenium
========================

We can use By.tagName to find elements under <iFrame>.


For that we must first switch to iFrame.
Then we can start locating it.

All the iFrames on any webpage/html will have index starting from 0.

A good approach to locate any element under <iFrame> is to first get the number of <iFrame> available on the HTML page.
For that we must use findElementS method which returns the list of webelements. We count the size of that list to determine how many iFrame elements are there on the page.

And as we know, index for iFrame starts with 0, we can go to desired iFrame tag based on that index.(57:00)

With switchTo.frame() method we can switch to our desired iFrame
driver.switchTo.frame(ID)
driver.switchTo.frame(name)
driver.switchTo.frame(WebElement)

Then we can use our normal locating methods to locate elements under that <iFrame>
