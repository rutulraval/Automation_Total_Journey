How do you handle dropdown in Selenium ?
========================================
Selenium API gives us Select class

Its constructor takes a webelement as an argument.

Select dropDown = new Select(element);

and using the object of Select class, we can invoke methods like selectByVisibleText, selectByValue, selectByIndex.
