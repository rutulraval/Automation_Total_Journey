EXPLICIT WAIT
------------
-1:30:00

We can tell webdriver to wait using static methods of class ExpectedConditions and wait for a certain element to be in a particular state. And that wait will be for a specified amount of time for that particular element only, not for entire DOM. If that element is not in the desired state within that time limit, we may get TimeOutException.

There are various methods based on desired outcomes related to webelements, we can use those static methods to make the webdriver wait explicitly for those conditions to happen.

First, we have to make an object of WebDriverWait

WebDriverWait wait = new WebDriverWait(driver, 10);

then, we go for our WebElement

WebElement element = wait.until(ExpectedConditions.elementToBeClickable(By.id("abcd")));



IMPORTANT INTERVIEW QUESTION
--=========================--

Diff. between IMPLICIT WAIT and EXPLICIT WAIT ?
- implicit wait is for entire DOM and All elements, Explicit wait is for particular element only.

01:43:00
===========
We can generalize this explicit wait mechanism by defining a static method which can take required time , By locator and WebDriver object as arguments and return WebElement as per custom wait time requirement.

public static getWebElementWithExplicitWait(WebDriver driver, int timeout, By locator){

//Here only we write generic code for WebDriverWait
WebDriverWait wait = new WebDriverWait(driver, timeout);

//And with arguments passed to this method and this wait object we find required element
WebElement element = wait.until(ExpectedConditions.elementToBeClickable(locator));
//in above line we can use any static method that we want
return element;
}

FluentWait
===================

It implements Wait interface, it is specialized version of Explicit Wait

It provides extra functionality.
Maximum amount of time to wait for a condition , as well as the frequency with which to check the condition.




Hierarchy of Wait interface
-------------------------------

Wait(interface) 
  |
  |
FluentWait(Class)
  |
  |
WebDriverWait(Class) used for Explicit wait execution

Implicit wait and Thread.sleep
=============================

Let's say Implicit wait has 30 seconds as time unit, but if the element is available within 5 seconds, execution will be resumed for further code. 

But, in case of Thread.sleep(5000), even if the elements are available within less time, the wait time will be maintained and no further execution will be done until that time limit has finished.
